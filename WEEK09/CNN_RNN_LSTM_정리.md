# CNN, RNN, LSTM 정리

## 1. CNN

**CNN**은 **Convolutional Neural Network**, 즉 **합성곱 신경망**이다.

주로 **이미지 데이터 처리**에 많이 사용된다.

이미지는 픽셀들이 가로와 세로 방향으로 배치되어 있기 때문에, CNN은 이미지 안에서 **특징을 찾아내는 데 강한 모델**이다.

예를 들어 고양이 사진을 분류할 때 CNN은 처음에는 선, 모서리 같은 단순한 특징을 찾고, 점점 눈, 귀, 얼굴 모양 같은 복잡한 특징을 학습한다.

### CNN의 핵심 개념

| 개념 | 설명 |
|---|---|
| 합성곱 | 이미지의 작은 영역을 훑으면서 특징을 추출하는 과정 |
| 필터/커널 | 이미지에서 특정 특징을 찾기 위한 작은 행렬 |
| 특징맵 | 필터를 적용한 결과로 만들어지는 새로운 데이터 |
| 풀링 | 중요한 정보만 남기고 크기를 줄이는 과정 |
| 완전연결층 | 추출된 특징을 바탕으로 최종 분류를 수행하는 층 |

### CNN의 흐름

```text
입력 이미지
↓
합성곱층
↓
활성화 함수
↓
풀링층
↓
완전연결층
↓
출력
```

### 예시

```text
고양이 이미지 입력
↓
선, 모서리 특징 추출
↓
눈, 귀, 털 모양 특징 추출
↓
고양이인지 강아지인지 분류
```

### CNN이 자주 사용되는 분야

| 분야 | 예시 |
|---|---|
| 이미지 분류 | 고양이/강아지 분류 |
| 객체 탐지 | 사진 속 사람, 자동차 찾기 |
| 얼굴 인식 | 얼굴 인증 시스템 |
| 의료 영상 분석 | X-ray, CT 이미지 분석 |
| 자율주행 | 차선, 보행자, 표지판 인식 |

---

## 2. RNN

**RNN**은 **Recurrent Neural Network**, 즉 **순환 신경망**이다.

주로 **순서가 있는 데이터**를 처리할 때 사용된다.

예를 들어 문장, 음성, 주식 가격, 날씨 데이터처럼 앞의 정보가 뒤의 결과에 영향을 주는 데이터에 적합하다.

일반 신경망은 입력을 각각 독립적으로 처리하지만, RNN은 이전 시점의 정보를 기억해서 다음 시점의 계산에 사용한다.

### RNN의 핵심 개념

| 개념 | 설명 |
|---|---|
| 순환 구조 | 이전 결과를 다음 계산에 다시 사용하는 구조 |
| 은닉 상태 | 이전 시점의 정보를 저장하는 값 |
| 시계열 데이터 | 시간 순서가 있는 데이터 |
| 순차 데이터 | 순서가 중요한 데이터 |

### RNN의 흐름

```text
입력1 → RNN → 출력1
          ↓
입력2 → RNN → 출력2
          ↓
입력3 → RNN → 출력3
```

조금 더 쉽게 보면 다음과 같다.

```text
나는
↓
오늘
↓
학교에
↓
간다
```

RNN은 “나는”, “오늘”, “학교에”라는 앞 단어 정보를 참고해서 다음 단어나 문장의 의미를 예측할 수 있다.

### RNN이 자주 사용되는 분야

| 분야 | 예시 |
|---|---|
| 자연어 처리 | 문장 분류, 번역, 감정 분석 |
| 음성 인식 | 음성을 텍스트로 변환 |
| 시계열 예측 | 주가, 날씨, 센서 데이터 예측 |
| 문장 생성 | 다음 단어 예측 |
| 챗봇 | 대화 문맥 처리 |

### RNN의 한계

RNN은 이전 정보를 기억할 수 있지만, **긴 문장이나 긴 시간 데이터**에서는 오래전 정보를 잘 기억하지 못하는 문제가 있다.

이를 **장기 의존성 문제**라고 한다.

---

## 3. LSTM

**LSTM**은 **Long Short-Term Memory**, 즉 **장단기 기억 신경망**이다.

RNN의 한계를 보완한 모델이다.

즉, LSTM은 RNN처럼 순서가 있는 데이터를 처리하면서도 **중요한 정보는 오래 기억하고, 불필요한 정보는 잊도록 설계된 모델**이다.

### LSTM의 핵심 개념

| 개념 | 설명 |
|---|---|
| 셀 상태 | 장기 기억을 저장하는 통로 |
| 은닉 상태 | 현재 시점의 출력 정보 |
| 게이트 | 정보를 기억할지, 버릴지 조절하는 장치 |
| 입력 게이트 | 새로운 정보를 얼마나 저장할지 결정 |
| 삭제 게이트 | 이전 정보를 얼마나 잊을지 결정 |
| 출력 게이트 | 어떤 정보를 다음 출력으로 보낼지 결정 |

### LSTM의 흐름

```text
이전 정보
↓
삭제 게이트: 필요 없는 정보 제거
↓
입력 게이트: 새로운 정보 저장
↓
셀 상태: 중요한 정보 유지
↓
출력 게이트: 다음 단계로 정보 전달
```

쉽게 말하면 LSTM은 RNN보다 **기억력이 좋은 신경망**이다.

### LSTM이 자주 사용되는 분야

| 분야 | 예시 |
|---|---|
| 자연어 처리 | 번역, 감정 분석, 문장 생성 |
| 음성 인식 | 음성 문맥 파악 |
| 시계열 예측 | 주가, 전력 사용량, 날씨 예측 |
| 이상 탐지 | 센서 데이터 이상 감지 |
| 챗봇 | 긴 대화 흐름 처리 |

---

## 요약

**CNN**은 이미지의 특징을 찾는 모델이고,  
**RNN**은 순서가 있는 데이터를 처리하는 모델이며,  
**LSTM**은 RNN의 기억력 부족 문제를 개선한 모델이다.

---

## 한눈에 비교

| 구분 | CNN | RNN | LSTM |
|---|---|---|---|
| 전체 이름 | Convolutional Neural Network | Recurrent Neural Network | Long Short-Term Memory |
| 한국어 | 합성곱 신경망 | 순환 신경망 | 장단기 기억 신경망 |
| 주로 쓰는 데이터 | 이미지, 영상 | 문장, 음성, 시계열 | 문장, 음성, 시계열 |
| 핵심 역할 | 공간적 특징 추출 | 순서 정보 학습 | 긴 순서 정보 학습 |
| 장점 | 이미지 특징 추출에 강함 | 순서가 있는 데이터 처리 가능 | 긴 문맥을 비교적 잘 기억 |
| 단점 | 순서 데이터 처리에는 약함 | 긴 문맥 기억이 어려움 | 구조가 복잡하고 계산량이 많음 |
| 대표 활용 | 이미지 분류, 객체 탐지 | 문장 분석, 시계열 예측 | 번역, 감정 분석, 장기 시계열 예측 |
